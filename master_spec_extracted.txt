- ADC below 250: `Dark`.

## 8. AUTHORITATIVE ROOM COMFORT INDEX ENGINE

Implement one authoritative backend RCI calculation. Do not duplicate or override the formula in frontend JavaScript.

All component weights and threshold settings must be configurable.

### 8.1 Overall formula

Let:

\[
\mathrm{RCI}=\sum_i w_i s_i
\]

where the active weights \(w_i\) are normalised and component scores \(s_i\) fall in the range 0–100.

Initial weights:

| Component | Weight |
|---|---:|
| Temperature | 0.30 |
| Relative humidity | 0.25 |
| MQ-135 relative gas response | 0.25 |
| LDR brightness | 0.10 |
| Sound activity | 0.10 |

Inspect existing RCI/intelligence code first. Reuse useful, tested logic when appropriate, but document the final implemented formula exactly.

### 8.2 Temperature component

Weight: `0.30`.

- Optimal band: 21–24 °C → score 100.
- From 14 °C up to but below 21 °C:

\[
s_{\text{temp}}=\frac{T-14}{21-14}\times100
\]

- From above 24 °C through 33 °C:

\[
s_{\text{temp}}=\frac{33-T}{33-24}\times100
\]

- Below 14 °C or above 33 °C: score 0.

Clip the result to 0–100.

Define boundary behaviour explicitly and test the endpoints.

### 8.3 Relative-humidity component

Weight: `0.25`.

- Optimal band: 40–60% → score 100.
- From 15% up to but below 40%:

\[
s_{\text{rh}}=\frac{\mathrm{RH}-15}{40-15}\times100
\]

- From above 60% through 85%:

\[
s_{\text{rh}}=\frac{85-\mathrm{RH}}{85-60}\times100
\]

- Below 15% or above 85%: score 0.

Clip the result to 0–100.

### 8.4 MQ-135 relative gas-response component

Weight: `0.25`.

When the baseline is valid:

\[
\mathrm{ratio}=\frac{\mathrm{MQ135}_{\mathrm{raw}}}{\mathrm{MQ135}_{\mathrm{baseline}}}
\]

- Ratio at or below 1.05: score 100.
- Ratio at or above 2.50: score 0.
- Otherwise:

\[
s_{\text{gas}}=
\left(1-\frac{\mathrm{ratio}-1.05}{2.50-1.05}\right)\times100
\]

Clip to 0–100.

Do not score the gas component as fully valid when the baseline is not ready or the baseline denominator is invalid.

This score represents a relative sensor response, not measured pollutant concentration.

### 8.5 LDR component

Weight: `0.10`.

Use verified thresholds:

- Bright, ADC at least 1700: score 100.
- Dim, ADC 250–1699: score 85.
- Dark, ADC below 250: score 50.

These values are configurable project-design choices. Do not describe this score as a universal lighting standard.

### 8.6 Sound component

Weight: `0.10`.

Use current analog swing, repeated digital threshold triggers and their persistence:

- Quiet/stable: score 100.
- Moderate background activity: score 80.
- Frequent threshold triggers or sustained high analog swing: score 40.

Use deterministic, documented thresholds and configurable settings based on the existing firmware values.

Do not claim calibrated dB measurements.

### 8.7 Missing Data and Freshness

Never replace missing or invalid readings with zero.

If a component is missing or invalid, remove its weight from the active weight sum:

\[
W_{\text{active}}=\sum_{k\in\text{valid}}w_k
\]

When the core temperature and humidity readings are valid, calculate the provisional score as:

\[
\mathrm{RCI}_{\text{provisional}}
=
\frac{\sum_{k\in\text{valid}}w_k s_k}{W_{\text{active}}}
\]

Return `Indeterminate / Stale Telemetry` with `score: null` when:

- Core temperature or humidity inputs are missing.
- Data coverage is below 50%.
- Required telemetry is stale beyond the configured threshold, initially 120 seconds.
- No valid component weights remain.

If coverage is below 100%, or the MQ-135 baseline is not ready, mark the score provisional and reduce confidence appropriately.

### 8.8 RCI Response Schema

Return at least:

- `score`
- `status`
- `color_band`
- `is_provisional`
- `is_stale`
- `data_coverage_percent`
